# سطر الأوامر والوكلاء

كل تثبيت يشحن أمر `vantage` يقود المحركات نفسها التي تستخدمها النافذة — المحلّلات نفسها، والكاتب نفسه، والمحرّك نفسه. الملف الذي يحفظه التطبيق والملف الذي يكتبه الأمر هما الملف نفسه، والفحص الذي يجتازه لوحة الذكاء الاصطناعي في التطبيق يجتازه الأمر أيضًا.

```sh
vantage --help          # every command
vantage guide slides    # the op reference, for writing your own
```

هذه هي الواجهة كاملة في شاشة واحدة — كل أمر مع سطر يشرح ما يفعله، ثم الخيارات العامة ورموز الخروج:

## الحصول على الأمر

في macOS وWindows يأتي الأمر داخل حزمة التطبيق. لمناداته بالاسم شغّل `vantage install-cli` مرة واحدة: يصل الملف الثنائي من الحزمة بدليل على PATH لديك — في macOS إلى ‎/usr/local/bin‎ ما لم يكن بادئة Homebrew ‏(أدلة Homebrew نفسها لا تُمس أبدًا)، وإلا إلى دليل bin الخاص بك — أو في Windows إلى ‏`PATH`‎ المستخدم.

## الأوامر التي تستحق المعرفة

| الأمر             | وظيفته                                                                                                                                                                                        |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `open`            | فتح مستند داخل التطبيق؛ ويشغّل التطبيق إن لم يكن يعمل.                                                                                                                                        |
| `selection`       | ما يختاره المستخدم في ذلك الملف في هذه اللحظة، ما دام التطبيق يعمل — إشارة «هذا» / «هنا». ويعيد نطاق كتل، أو نطاقًا في الجدول، أو عناصر شريحة، أو صفحة، أيًّا كان المحرّر المفتوح عليه الملف. |
| `convert`         | التحويل بين الصيغ باستخدام محركات التطبيق نفسها.                                                                                                                                              |
| `create`          | إنشاء مستند من محتوى منظَّم.                                                                                                                                                                  |
| `render`          | صورة PNG لكل صفحة، بالتخطيط الذي ينفّذه المحرّك.                                                                                                                                              |
| `pdf`             | قراءة الطبقة النصية لملف PDF صفحةً بصفحة، دون أي عملية تطبيق.                                                                                                                                 |
| `info`            | البيانات الوصفية وملخّص لبنية المستند.                                                                                                                                                        |
| `search`          | بحث في الويب أو الصور عبر المزوّد المهيّأ في التطبيق.                                                                                                                                         |
| `image` / `media` | توليد صورة، أو وصف صورة أو ملف فيديو أو صوتي والسؤال عنه.                                                                                                                                     |
| `merge`           | ملء العناصر النائبة `{{key}}` في قالب `.docx` أو `.pptx` أو `.xlsx`.                                                                                                                          |
| `capabilities`    | الإبلاغ عن ميزات السحابة المهيّأة على هذا الجهاز.                                                                                                                                             |
| `guide`           | مرجع العمليات وأدلة التصميم، مولَّد من التعريفات نفسها التي يتحقق منها المنفّذ — لذا لا يمكن أن ينحرف عمّا يقبله `apply`. ويعيد `--json` المرجع مع مخطط كل عملية.                             |
| `install-cli`     | وضع `vantage` في `PATH`.                                                                                                                                                                      |
| `skill`           | عرض وكلاء البرمجة الموجودين على هذا الجهاز وتثبيت مهارة Vantage فيها أو تحديثها.                                                                                                              |
| `mcp`             | تقديم كل أمر كأداة ضمن Model Context Protocol. انظر **ربط وكيل برمجي**.                                                                                                                       |

## التحرير: مستندات وجداول وعروض

`vantage docs` و`vantage sheet` و`vantage slides` تقرأ وتحرّر عبر مسار الكتابة نفسه الذي يستخدمه التطبيق، وهي تتشارك مفردات واحدة: **العملية** (op) هي تعديل واحد، و**المواصفة** (spec) قائمة عمليات تُطبَّق بالترتيب.

```sh
vantage sheet read report.xlsx
vantage slides apply deck.pptx --ops ops.json --dry-run
vantage docs apply brief.docx --ops ops.json
```

يعرض `--dry-run` ما ستفعله دفعة ولا يكتب شيئًا، وهذه أرخص طريقة للتحقق من مواصفة قبل تطبيقها. ولوحة الذكاء الاصطناعي في التطبيق تعمل على هذه العمليات بالضبط، فأي شيء تطلبه منها يمكنك برمجته.

## Model Context Protocol

يقدّم `vantage mcp` كل أمر كأداة MCP، ويسجّل `vantage mcp install <agent|all>` في إعداد وكيل البرمجة نفسه. انظر **ربط وكيل برمجي** لتلك الجهة.

## ما لا يفعله الأمر

هو يقرأ الملف ويكتبه. لكنه ليس التطبيق: لا توجد نافذة، ولا ينطبق حوار التحديث داخل التطبيق. وأي شيء يحتاج إلى النافذة — لوحة الذكاء الاصطناعي، أو مراجعة الجودة QC لشريحة مُعرضة — عليه أن ينتظر حتى تفتح الملف. ويمنحك `vantage render` البكسلات دون ذلك، وتُدقّق `vantage slides` في تخطيط العرض بنفسها.
